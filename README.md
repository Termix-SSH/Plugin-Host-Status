<h1>Host Status</h1>

<p>Shows if each host is online with a dot in the host list, checked by connecting to its port</p>

</div>

<br />

## Overview

Host Status adds the online or offline dot next to every host. It connects to the host's port on a timer and never logs in.

Read the [docs](https://docs.termix.site/plugins/host-status) to set it up and use it.

<br />

## Features

- An online or offline dot for every host
- Checks the host's port and never logs in
- Checks through jump hosts
- An open session or a working login counts as online
- Set the check interval for everyone or for one host
